## 🌿 개발할 때 중요하게 생각하는 것

- **문제의 출발점** — 기능을 만들기 전에, 어떤 불편을 해결할지 생각합니다.
- **기록의 정확성** — 금액과 날짜처럼 작은 오류가 큰 차이를 만드는 데이터를 신중하게 다룹니다.
- **사용의 흐름** — 입력부터 결과 확인까지 사용자의 동선을 생각합니다.
- **끝까지 이어가기** — 구현한 기능이 실제 사용으로 이어지도록 완성해 나갑니다.
